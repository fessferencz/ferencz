# Установка Miron Skills в Codex: практика

Это инструкция для **Codex, запущенного в нужном веб-проекте**. В репозитории `fessferencz/ferencz` лежит библиотека; она не меняет файлы проектов на собственных серверах автоматически.

## Вариант A — для конкретного проекта (лучший, если участвует команда)

Откройте нужный сайт или приложение в Codex и отправьте:

> Установи навыки Marketing Skills из публичного репозитория https://github.com/fessferencz/ferencz в `.agents/skills/` **текущего проекта**. Перенеси только папки, начинающиеся с `marketing-`, сравни с имеющимися и ничего не перезаписывай без просмотра diff. Не копируй чужой `AGENTS.md` поверх нашего; аккуратно добавь ссылку на навыки в действующие инструкции. Не меняй исходный код сайта, зависимости, серверы, секреты и production. Проверь все новые `SKILL.md` и что они видны Codex. Покажи список и `git status`.

Для ручной установки из терминала Linux/macOS **в рабочем каталоге нужного проекта**:

```bash
# из корня проекта (проверить pwd и git status)
cd /path/to/your/project
mkdir -p .agents/skills
# не используем /tmp с существующими файлами
workdir="$(mktemp -d)"
git clone --depth=1 https://github.com/fessferencz/ferencz.git "$workdir/miron-skills"
# Перед копированием проверьте совпадающие названия skills.
for src in "$workdir"/miron-skills/.agents/skills/marketing-*; do
  name="$(basename "$src")"
  if [ -e ".agents/skills/$name" ]; then
    printf 'SKIP existing: %s\\n' "$name"
  else
    cp -R "$src" ".agents/skills/$name"
    printf 'ADDED: %s\\n' "$name"
  fi
done
git status --short
```

Проверьте `/skills` в Codex (или начните вводить `$marketing-`). Если навыки не появились, перезапустите Codex. Не запускайте команды из неизвестного источника без просмотра.

## Вариант B — один раз для пользователя Codex на машине

Если Codex используется **в нескольких проектах** под одной учётной записью ОС, можно установить все маркетинговые навыки в `~/.agents/skills/` вместо проектной папки. Они будут доступны для проектов этого пользователя на этой машине. На другом сервере или компьютере установка отдельная.

В Codex можно попросить:

> Установи только маркетинговые навыки `marketing-*` из https://github.com/fessferencz/ferencz в мою пользовательскую директорию `~/.agents/skills/`. Перед изменением проверь существующие названия, не перезаписывай без моего разрешения, не трогай проекты и рабочие серверы. В конце покажи путь каждого установленного `SKILL.md` и предложи 3 тестовых запроса.

## Вариант C — использование без установки

Для разового эксперимента можно попросить Codex прочитать конкретный `SKILL.md` в GitHub (при наличии доступа к сети), а затем применить методику без записи файлов. В следующем запуске она может потребовать повторного чтения.

## Проверка вызова

После установки запустите `/skills`, затем попробуйте:

```text
$marketing-strategy Для текущего проекта предложи 5 проверяемых гипотез повышения конверсии. Данные не придумывай, код не меняй.
```

```text
$marketing-seo-brief Составь SEO-бриф текущей страницы услуги для региона проекта. Укажи, каких данных не хватает.
```

```text
$marketing-campaign-analytics Спроектируй измерение сезонной рекламной акции с контрольной группой. Реальные результаты не выдумывай.
```

Навыки можно запускать **явно** через `$name`, а также Codex может выбирать их автоматически по описанию. Автоматический выбор не гарантирован для любого текста: когда важна точная методика, называйте её сами.

## Как обновлять

Установленные в проект копии навыков не синхронизируются автоматически с библиотекой. Периодически сравнивайте `SKILL.md` в рабочем проекте с `main` библиотеки, переносите изменения после ревью и коммита.

## Безопасность

Навыки не требуют прямого доступа к production. Внутри только Markdown. Реальные рекламные рассылки, публикации, использование персональных данных, изменение бюджета — после отдельного согласования и при наличии подключённых систем.
