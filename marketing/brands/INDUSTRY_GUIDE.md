# Отраслевые сценарии маркетинга

Этот файл содержит **возможные направления анализа**, а не утверждения о конкретных предприятиях.

## Рестораны

Задачи: первый визит → второй визит, возвращение гостей, частота посещений, заполняемость непиковых часов, качество сервиса, прибыльность предложения.

Сегменты для проверки: новые гости, постоянные, давно не посещавшие, отдельные предпочтения по продукту, каналы и периоды. Если данные не позволяют обоснованно выделить сегмент, не создавать его искусственно.

Проверка акции: учитывать фудкост, допродажи, скидки, загрузку кухни, персонал, отмены, инкрементальность и риск каннибализации полной цены. Не объявлять повышение посещаемости доказанной причинностью без контроля.

## Шиномонтаж

Задачи: сезонная запись, возврат клиентов по истории визитов, удобство онлайн-записи, снижение отказов и неявок, повторные покупки вне пиковых периодов.

Сегменты для проверки: город/объект, история сезонных визитов, тип услуги, канал обращения, время записи, доступность слотов. Учитывать погоду, календарь, число работающих постов, фактическую загрузку, сезонную базу сравнения.

Проверка акции: не считать рост выручки без учёта сезона «доказанным эффектом рекламы». Избегать обещаний слота, цены или скидки без проверки действующих условий.

## Розница

Задачи: возврат покупателей, частота покупки, категории, доступность товара, промо без разрушения маржи, работа с локальными магазинами.

Проверка: сопоставимость магазинов, отсутствие товара, перемещение продаж между периодами, суммарная маржа после скидки, повторные покупки. Не обещать наличие товара без фактического остатка.

## Общий принцип

Маркетинг не исправляет неисправный процесс. Если наблюдаемый провал объясняется очередями, ошибками записи, отсутствием товара, плохим качеством обслуживания или иным операционным сбоем, сначала предложить операционную меру и только затем продвижение.
