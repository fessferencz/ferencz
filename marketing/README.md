# Miron Marketing Skills — версия для ChatGPT и Codex

Практический набор маркетинговых методик для нескольких брендов: ресторанов, сети шиномонтажей, розницы и веб-сервисов. Создан на основе анализа [marcosmodly/marketing-skill](https://github.com/marcosmodly/marketing-skill), адаптирован под русскоязычные команды, реальные данные, ChatGPT и Codex.

**Статус:** прототип на отдельной ветке. Сайт, серверы, рекламные кабинеты и рассылки не изменяются. Этот репозиторий публичный: никаких персональных данных, клиентских баз, секретов и приватных отчётов.

## Что работает и что не работает

- **Codex:** файлы \`SKILL.md\` размещаются в \`.agents/skills/\` конкретного проекта или в пользовательской папке навыков. При подключении Codex может использовать их по соответствующей задаче.
- **ChatGPT с поддержкой Skills:** папка \`marketing/chatgpt/marketing-studio/\` подготовлена как самостоятельный навык. Создание/установка через интерфейс Skills зависит от тарифа и прав рабочей области; само наличие GitHub-файлов не устанавливает навык автоматически.
- **Обычный чат / ChatGPT Project:** возьмите \`marketing/CHATGPT_PROJECT_INSTRUCTIONS.md\` как инструкции проекта и прикрепите нужные Markdown-материалы. Это контекст и правила, **не** установленный Skill.
- **Интеграции:** реальные данные можно получать только через доступные подключённые приложения и разрешённые источники. Навыки не создают подключений и не выдают доступ к рекламным кабинетам или серверам.
- **Видео:** навыки создают сценарии, раскадровки и задания; MP4 появляется только при наличии отдельного инструмента и реального исполнения.
- **Публикации / email / SMS:** по умолчанию только черновики и предпросмотр. Никаких отправок, платных рекламных действий и запусков через webhook без отдельного явного подтверждения.

## Начало работы в ChatGPT

1. Откройте [CHATGPT_PROJECT_INSTRUCTIONS.md](CHATGPT_PROJECT_INSTRUCTIONS.md) и добавьте инструкции в свой ChatGPT Project, если функция Project доступна.
2. Прикрепите [marketing-studio/SKILL.md](chatgpt/marketing-studio/SKILL.md) и нужные справочные Markdown-файлы. Если есть возможность установки Skills, используйте всю папку \`chatgpt/marketing-studio/\` вместе с \`references/\`.
3. Для каждого бренда задайте факты и согласованный стиль по [бренд-шаблону](brands/BRAND_TEMPLATE.md). Храните заполненные приватные карточки вне публичного GitHub.
4. Пример запроса: «Используй маркетинговые инструкции проекта. Подготовь гипотезы возврата гостей ресторана: сначала сегменты, затем офферы, каналы, экономика и тест».

[Официально: Skills в ChatGPT](https://help.openai.com/en/articles/20001066-skills-in-chatgpt) и [Skills для Codex](https://developers.openai.com/codex/skills/).

## Начало работы в Codex

Скопируйте только требуемые каталоги \`.agents/skills/marketing-*/\` в тот репозиторий, в котором запускаете Codex. Не переписывайте существующий \`AGENTS.md\`; объединяйте правила осознанно.

Можно проверить наличие навыков в Codex и вызвать конкретный: \`$marketing-strategy\`, \`$marketing-competitor-research\`, \`$marketing-campaign-analytics\`.

## Общие требования

**Честность данных:** нельзя придумывать продажи, выручку, CTR, маржу, цены, скидки, отзывы, доступность услуг и результаты A/B-тестов. Предположения помечать как гипотезы.

**Регуляторика:** перед реальными рекламными рассылками и публикациями проверять согласия, обработку персональных данных, правила каналов и применимые требования к маркировке рекламы. Навык не подменяет юридическую проверку.

**Конфиденциальность:** никакие реальные телефоны, email-адреса клиентов, идентификаторы, рекламные токены и выгрузки CRM не коммитить в публичный репозиторий.

**Управление:** без явного разрешения не отправлять, не публиковать, не запускать кампании, не менять рекламные бюджеты и не создавать массовые задания.
