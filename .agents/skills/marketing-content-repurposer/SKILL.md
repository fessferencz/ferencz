# Content Repurposing

1. Установить первоисточник: документ, объявление, карточка услуги, сайт, протокол или пользовательский текст. Извлечь подтверждённые факты, конкретный оффер и CTA.
2. Проверить, можно ли публично использовать данные и имена; внутренние документы могут содержать конфиденциальное.
3. Для каждой названной площадки сделать отдельную версию — короткий hook, структура, длина, стиль, CTA, ссылка. Не делать механическое обрезание одного поста.
4. Проверить сохранность всех условий: дата, город, ограничения, цена, скидка, порядок действий.
5. При отсутствии подтверждения заменить обещание на уточнение в брифе; не писать как факт.
6. Пометить черновики по каналу и дать короткие рекомендации по визуалу.

## Выход

Исходные факты → Telegram/VK/email/сайт (только нужные) → список утверждений, требующих проверки → контроль совпадения оффера.

Не публиковать без отдельного разрешения. При работе с маркетинговым email учитывать согласия и отписки.
