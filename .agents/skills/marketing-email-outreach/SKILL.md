# B2B Outreach — черновики и контроль

1. Определить ICP: отрасль, роль, география, реальная потребность, коммерческое предложение и отправитель.
2. Для каждого потенциального получателя использовать только реально предоставленные/разрешённые данные; не угадывать контакт и не дополнять фиктивными именами или адресами.
3. Проверить основание для контакта, применимые правила рекламы и обработки данных, отписки, истории отказов и повторов; без надёжного журнала не утверждать, что контакт «новый».
4. Составить персональное письмо на основе **конкретного проверенного** факта. Не создавать псевдоперсонализацию.
5. Для каждого письма дать цель, проверенный факт, текст, CTA, контекст контакта и статус Draft / Review.
6. Никакой отправки без отдельного подтверждения финального получателя, текста, канала, частоты и допустимости.

## Выход

Короткая стратегия → шаблон → проверяемый персональный вариант → список открытых вопросов по контакту и согласиям → список исключений.

Не создавать и не коммитить контактные таблицы в публичный GitHub. Не использовать этот навык для массового спама.
