# Creative Brief, Short Video & Montage

## Выбрать тип результата

- Статичный визуал: ключевая идея, композиция, формат, текст, цветовая система, изображение, разрешённые бренд-активы.
- Короткий ролик: 0–3 секунды hook, далее демонстрация/доказательство, в конце действие.
- Монтаж из материалов заказчика: инвентаризация клипов, сильные моменты, порядок, таймкоды, озвучка, титры, музыка и финальная карточка.

## Процесс

1. Цель, аудитория, площадка, длительность, формат (например 9:16), бренд и ограничения.
2. Отделить реальные фото/видео и подтверждённые утверждения от вымышленных сцен.
3. Сформировать последовательность кадров (сцена, время, действие, текст на экране, звук, переход, CTA).
4. Для генерации — самостоятельный промпт на каждый кадр + общая консистентность бренда.
5. Проверить права на клипы, лица, музыку, логотипы и указанные цены/условия.
6. Только при реально доступном инструменте создавать ассет; без него отдавать сценарий и план. Не заявлять «видео готово», если MP4 не рендерился.

## Результат

Цель → key message → формат → раскадровка в таблице → тексты/промпты → список исходников → чек-лист финального монтажа → статус: «бриф» / «визуал» / «рендер», только по факту.

Скрипты стороннего видеорендерера и внешние API автоматически не скачивать и не запускать.
