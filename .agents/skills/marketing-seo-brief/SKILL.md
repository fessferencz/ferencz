# SEO Brief

## Исследование

- Уточнить объект, географию, язык, действующую страницу и цель: запись/звонок/визит/заказ.
- Найти первичные формулировки запроса и намерения пользователя. Разделять информационные, коммерческие и навигационные запросы.
- Изучить реальную выдачу/конкурентов, если есть веб-доступ; без доступа не выдавать свой список за измеренную частотность.
- Отдельно проверить локальную релевантность, страницы объектов, адреса, часы, услуги и единообразие контактных данных.

## Бриф

1. Главный интент и ключевые кластеры без выдуманного volume.
2. Рекомендуемый URL и структура H1/H2/H3.
3. Основные ответы и блоки услуг/доверия/FAQ.
4. Title, meta description, schema.org при обоснованной уместности и технической корректности.
5. CTA, внутренняя перелинковка, мобильный путь, Core Web Vitals как проверяемая гипотеза, не вымышленный показатель.
6. Индексация, канонические URL, дубли, локальные страницы — только по действующей архитектуре.
7. План измерений: реальные показы/клики/позиции/конверсии из доступных проверенных систем.

## Ограничения

Не обещать позиции, не выдумывать частотность, не плодить тонкие дубли региональных страниц. Для существующего сайта сначала исследовать стек и маршруты; не менять их в задаче только на бриф.
