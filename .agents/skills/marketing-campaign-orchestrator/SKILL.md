# Marketing Campaign Orchestrator

## Поток

1. Определить бизнес-цель, бренд, ограничения, целевое действие и baseline.
2. Запустить \`marketing-competitor-research\` только если нужны внешние сравнения; использовать достоверные данные.
3. Использовать \`marketing-strategy\` для сегментов, оффера, операционных ограничений и экономики.
4. Для привлечения: \`marketing-seo-brief\` / \`marketing-ad-copy\` / \`marketing-content-calendar\` по реально нужным каналам.
5. Для возвращения клиентов: \`marketing-email-sequence\` / \`marketing-content-repurposer\`, только с корректным правом на коммуникацию.
6. Для креатива: \`marketing-creative-brief\`; рендер отдельной задачей при наличии инструмента.
7. Для измерения: \`marketing-campaign-analytics\`, контроль/сопоставимость и стоп-условия.
8. Перед публикацией/отправкой: \`marketing-publication-review\` и **отдельное явное согласование**.

## Основной результат

Одна карточка кампании: цель, сегмент, гипотеза, оффер и подтверждения, календарь, тексты, креативы, каналы, бюджет и ограничения, экономика, эксперимент, KPI, риски и статус согласования.

Условия: ни один канал не активируется по фразе «сделай всю кампанию» без отдельно проверенного действия и подтверждения. Не выполнять производство/рассылки/публикации, если пользователь просит только план.

Статусы: Strategy → Draft → Review → Approved → Scheduled → Live → Measured. Статус Live возможен только при фактическом подтверждённом действии.
